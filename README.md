A one-sentence startup pitch for make.fun's "Ridiculous at First Glance, Real by the Second" bounty: a crow-powered cigarette-butt cleanup service that sounds like a joke until the unit economics land — cities pay per kilo, and a crow works for peanuts. `main.py` writes the pitch (one sentence, under 200 characters) to `$MAKEFUN_OUTPUT_DIR/entry.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py && cat /tmp/out/entry.txt
```
